# CHITIN: Molt of the Last Hive
Mobile post-apocalyptic RPG (Godot 4.7). Humans mutated into insects; you play a *bloodline* that molts, speaks in scent and meets its past selves. See `docs/GDD.md`.

    godot --path chitin                                   # play (WASD move, J bite, K/L/; abilities, Q scent panel, F emit, E molt)
    godot --headless --path chitin --import               # first time only
    godot --headless --path chitin --script tests/run_tests.gd
    godot --headless --path chitin -- --smoke
