# Assets and provenance (Stream B: world / ui / art)

## Non-procedural assets: none
Every mesh, texture-less material, shader, icon and screenshot in `world/`, `ui/`, `art/` is generated by code in
this repository. No imported models, textures, audio or fonts were added, and no third-party or supplied
(e.g. Judd's) models are used.

- Meshes: `world/mesh_kit.gd` (flat-shaded, vertex-coloured primitives), `world/props.gd` (fungal trees, mushrooms,
  reeds, ruins, toy houses, rocks, crystals, crop rows, banner), `world/farm_layer.gd` (farm plot stages),
  `world/player.gd` (leader character, original design: bean body, mushroom-cap hat).
- Terrain: `world/terrain_heights.gd` + `world/world_view.gd` (heightfield triangulated and bucketed into 8x8-hex chunks).
- Shaders (original, GLSL-like Godot shading language): `world/shaders/*`, `ui/shaders/tilt_shift.gdshader`.
- UI: built in code with `StyleBoxFlat`; "icons" are coloured swatches plus a letter. Text uses Godot's built-in
  default theme font (engine-bundled; not a project asset).
- Palette: authored in `world/biomes.gd` and `ui/ui_style.gd`.

## TEMP code
`world/stub_world_gen.gd` is a presentation-side fallback world generator used by tests and when no Rules world is
supplied. The shipping path is `world/rules_world_adapter.gd` (MatchState.world -> WorldData). The stub can be deleted
once nothing calls `StubWorldGen` (tests/world still do, to stay independent of Rules).

## Screenshots (`art/captures/*.png`)
Rendered by `tools/art_capture.gd` under `xvfb-run` with the OpenGL3 driver on Mesa llvmpipe (software GL).
They are evidence of what the scene looks like, not performance evidence. Regenerate:
`xvfb-run -a godot --path . --rendering-driver opengl3 --resolution 1280x720 -s tools/art_capture.gd`

## Cost notes (honest, desktop software GL; nothing here is an Android/phone measurement)
- World = 77 chunks (11x7 of 8x8 hexes). About 129k terrain triangles + ~30-57k water triangles + ~30k prop instances
  in ~565 MultiMeshes (a few hundred draws if the whole map were visible).
- In the capture harness a typical frame reported ~110 draw calls / ~38k primitives (frustum culling + 240 m prop
  range). Software GL ran ~10 fps there; that number says nothing about a GPU.
- CPU-side, measured headless: player+walk step ~30 us, fog reveal (4536-byte texture refresh) ~0.3 ms per hex
  crossing, `WorldData.walkable` ~4 us. World build is ~3 s synchronous on this machine; `WorldStage.start()` spreads
  chunk construction over frames (nearest chunks first).
- Tilt-shift is a 9-tap full-screen pass: set `WorldStage.tilt.enabled = false` on weak GPUs. Shadows are off by default.
- Unvalidated: real GPU frame time, mobile thermals, memory on device.
